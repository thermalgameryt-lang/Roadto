# Road to the Eight — iPhone-ready React app

## Run it
1. Install Node.js.
2. In this folder run:
   `npm install`
3. Then:
   `npm run dev`

## Put it on your iPhone Home Screen
Deploy the built app to any HTTPS host (for example Vercel or Netlify).
Open the deployed URL in **Safari on iPhone** → **Share** → **Add to Home Screen**.

The app stores logs, tests, reflections and swaps in the browser's `localStorage`, so the data stays on that device/browser.

## Build
`npm run build`
